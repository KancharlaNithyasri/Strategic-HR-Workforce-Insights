# Strategic-HR-Workforce-Insights
# 📊 Strategic HR Analytics: Uncovering Workforce Retention Drivers

An interactive, production-ready two-page Power BI dashboard designed to analyze employee turnover patterns and identify key behavioral risk drivers using the open-source IBM HR Analytics dataset.

## 🎯 Project Purpose
Instead of just presenting raw data charts, this report focuses on elegant UI/UX layout structures, professional spacing, and an intuitive business reading flow. It transitions stakeholders seamlessly from a high-level executive overview to an interactive root-cause deep dive.

## 🎛️ Dashboard Structure

### 🔹 Page 1: Executive Overview
* **Focus:** High-level organizational health tracking for executive leadership.
* **Key Elements:** Left-to-right reading flow mapping critical metrics (**Total Employees ➡️ Total Attrition ➡️ Attrition Rate**).
* **Design Priority:** Clean visual margins, clear categorical labels without truncation, and custom-formatted KPI metrics.

### 🔹 Page 2: Predictive Risk Deep Dive
* **Focus:** Granular breakdown of operational and behavioral turnover factors.
* **Key Elements:** Features an interactive **AI Decomposition Tree** allowing stakeholders to dynamically drill down and slice turnover metrics by organizational paths.
* **Design Priority:** Strict structural and thematic consistency matching the core theme of the executive overview.

## 💡 Key Analytical Insights
* **Overtime Impact:** A strong correlation exists between heavy overtime demands and accelerated employee attrition.
* **Role Vulnerability:** Departmental and role-specific analysis shows that **Sales Representatives** and **Laboratory Technicians** exhibit the highest turnover velocity across the dataset.

## 🛠️ Tech Stack & Tools Used
* **Microsoft Power BI Desktop:** Visual architecture, canvas design, and report layout.
* **Power Query Editor:** ETL process (Data extraction, transformation, and cleaning).
* **DAX (Data Analysis Expressions):** Custom measures and precision KPI formatting.
